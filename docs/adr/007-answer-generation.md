# ADR-007: Генерация ответа, политика отказа и цитаты

**Статус:** принято.

## Конвейер `/ask`
`вопрос → нормализация и язык → гибридный поиск → политика отказа → Gemini (structured output) → цитаты → ответ или отказ`.

## Решения
- **Отказ до вызова модели (FR-5)**, если фрагментов нет или лучшее косинусное сходство с вопросом ниже `REFUSAL_MIN_SIMILARITY`. Оценка RRF для этого не годится: она показывает только порядок (ADR-006). Сходство считается из dense-векторов того же поискового запроса, без лишнего обращения к Qdrant. **Порог 0,55 не откалиброван** — его подберут на золотом наборе (день 8).
- **Вторая линия.** Модель сама возвращает `refusal: true`, если во фрагментах ответа нет. Ответ без единой подтверждённой цитаты тоже превращается в отказ: неподтверждённый текст пользователь не видит.
- **Цитаты.** Модель возвращает номера фрагментов из контекста; номер вне переданных фрагментов отбрасывается. Полная проверка цитат (FR-6: цитата должна совпадать с переданным текстом, иначе ответ получает пометку `citation_warning`) — день 7.
- **Язык (FR-3).** Язык вопроса определяется по доле кириллицы (от 30%), поэтому русский вопрос с ECDIS или MOB остаётся русским. Язык явно передаётся модели, текст отказа локализован.
- **Structured output.** `response_schema` — Pydantic-модель `{refusal, answer, citations}`, `temperature=0`. Ответ, который не разобрался по схеме, даёт 503, а не мусорный текст.
- **Промпт — версионированный файл** `qa/prompts/answer.v1.md`, не строка в коде. Изменение промпта — новый файл `answer.v2` и прогон eval. Версия доступна у адаптера (`prompt_version`) и попадёт в журнал запросов (день 7).
- **Prompt injection.** Вопрос и фрагменты передаются как данные в тегах, а `<`, `>`, `&` и кавычки экранируются: текст документа не может закрыть тег `</passage>` и выдать продолжение за инструкцию. Промпт прямо запрещает выполнять указания из данных. Сценарии атак проверит eval (день 13).
- **Надёжность.** Один клиент Gemini на эмбеддинги и генерацию: таймаут 30 с и 3 попытки с экспоненциальной паузой. Ошибки провайдера дают 503 с `Retry-After`.
- **Модель** `gemini-3.8-flash` (стабильная Flash на ноябрь 2026); меняется через `GENERATION_MODEL`.
