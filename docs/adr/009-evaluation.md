# ADR-009: Оценка качества — золотой набор и `make eval`

**Статус:** принято.

## Набор
`eval/golden.yaml` — 30 вопросов по корпусу:
- 20 с ответом на языке документа (10 RU, 10 EN);
- 5 с ответом, но заданных на другом языке, чем документ;
- 5 без ответа.

Для каждого вопроса записаны точное название документа и часть пути раздела. Тест сверяет набор с реальной нарезкой корпуса: eval не может молча мерить попадание в несуществующий раздел.

## Метрики
- **hit@5 и MRR** — по вопросам с ответом: нашёлся ли ожидаемый раздел в первой пятёрке и на каком месте.
- **Точность отказов** — доля отказов на вопросах без ответа.
- **Ложные отказы** — доля отказов на вопросах с ответом.
- **Корректность цитат** — ответ процитировал ожидаемый раздел.
- **Доля `citation_warning`** и **задержка p50/p95** — по выполненным ответам.
- **Зазор сходства** — минимальное лучшее сходство у вопросов с ответом против максимального у вопросов без ответа. Середина зазора — подсказка для порога отказа.

Метрика без данных — «—», а не 0: «не измерено» не должно выглядеть как «плохо».

## Честность прогона
- **Вопросы задаёт настоящий `QuestionService`** — та же система, что видит пользователь, — от имени существующего пользователя, и журнал запросов это показывает.
- **Невыполненный случай.** Если провайдер не ответил (лимит, перегрузка), случай помечается невыполненным. Метрики ответов считаются по выполненным, а отчёт и README прямо пишут «неполный прогон».
- **Отчёт `eval/results/<дата>-<коммит>.json`** фиксирует модели, промпт, модель эмбеддингов и порог. Коммит получает пометку `+dirty`, если рабочее дерево не чистое.
- **Таблица в README** заменяется только между маркерами `eval:start` и `eval:end`, и пишет её только `make eval`.
- **`--retrieval-only`** меряет поиск, не тратя лимит генерации. На бесплатном тарифе Gemini это 20 ответов в сутки на модель (ADR-007).

## Первый прогон (12.11.2026, коммит `f69a68c`, только поиск)
- hit@5 = 1,00, MRR = 0,94.
- Не на первом месте только вопросы на другом языке (3 из 5 — на втором): BM25 через язык не помогает, их вытягивает dense-поиск.
- Сходство: у вопросов с ответом — от 0,66 (самые низкие — межъязыковые; на языке документа — от 0,72); у вопросов без ответа — до 0,63. Порог 0,55 пропускал бы к модели все вопросы без ответа. Решение по порогу — в ADR-010 (день 9).
