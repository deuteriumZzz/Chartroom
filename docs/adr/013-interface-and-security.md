# ADR-013: Интерфейс и защита HTTP-края

**Статус:** принято.

## Интерфейс — статические файлы без сборки
- **Что сделано.** Страница `/` (HTML + CSS + JS в `chartroom/ui/static`) ходит в тот же API: вход, вопрос (режим «процедуры» или «агент»), разбор отчёта по шаблону, загрузка документа для admin.
- **Отклонения от первоначального плана:** вместо Jinja2 + HTMX и Tailwind по CDN — ванильный JS. Аутентификация у нас Bearer-токен, а не сессия в cookie: HTMX пришлось бы подмешивать заголовок скриптом, то есть всё равно писать JS, плюс шаблонизатор и сервер-рендеринг ради четырёх форм. Так нет новых зависимостей и ни одного внешнего ресурса.
- **Токен хранится только в памяти страницы** (не в `localStorage`): XSS не унесёт его надолго, а после обновления страницы нужно войти снова — для демо это приемлемо.
- **Ответы модели и данные отчётов выводятся только через `textContent`,** никогда как HTML.
- **CSP страницы:** `default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self'`. Поэтому скрипт и стили вынесены в файлы: без inline-кода строгую политику можно включить. Swagger (`/docs`) грузит ресурсы с CDN, и CSP на него не ставится.

## Ограничение частоты
- **Что и сколько.** `/auth/login` — 10 запросов в минуту с одного IP (защита от подбора пароля), `/ask` и `/agent/ask` — 20 в минуту на пользователя (защита квоты LLM и кошелька). Лимиты — в настройках. Превышение — `429` с `Retry-After`.
- **Реализация.** Счётчик с фиксированным окном в Redis: `INCR` + `EXPIRE NX` + `TTL` одной транзакцией, поэтому ключ всегда получает срок жизни. Окно проще скользящего, а пограничный всплеск (до двух лимитов на стыке окон) для этой задачи терпим.
- **Redis недоступен — запросы пропускаются** и пишется предупреждение. Решение осознанное: из-за потери счётчика не должны отказывать вход и работа с процедурами. Для `/auth/login` подбор паролей остаётся дорогим из-за argon2.
- **Ограничение:** ключ входа — `request.client.host`. За обратным прокси нужно, чтобы uvicorn получал его адрес (`--proxy-headers`, `--forwarded-allow-ips`), иначе все клиенты окажутся «одним IP».

## Остальное
- **Заголовки:** `X-Content-Type-Options: nosniff` и `Referrer-Policy: no-referrer` на всех ответах.
- **Метрики:** `/metrics` (Prometheus) у каждого приложения со своим реестром. Эндпойнт открыт: закрывать его нужно на уровне сети.
- **Логи:** отдельный слой логирования (structlog) не добавлялся — хватает стандартного `logging`. Токены и пароли не попадают в логи: вход принимает пароль в теле формы, а не в URL, и тест это проверяет.
- **CI:** `pip-audit` по зафиксированным зависимостям (`make audit`) и `gitleaks` по истории.
- **Загрузка файлов** защищена с первых дней: лимит 20 МБ, тип по сигнатуре, защита от zip-бомб DOCX, разбор только в worker с таймаутом (ADR-004).
